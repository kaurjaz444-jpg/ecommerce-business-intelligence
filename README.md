# E-Commerce Business Intelligence & Customer Analytics

## 1. Project Overview

This project focuses on analysing an international e-commerce marketplace using data analytics and business intelligence techniques.

The objective is to transform raw business data into meaningful insights that support better business decisions.

The project uses the Brazilian E-Commerce Public Dataset by Olist.

## 2. Business Problem

E-commerce businesses generate large amounts of data through customer orders, payments, product purchases, seller activities and customer reviews.

However, raw data alone cannot explain business performance.

This project aims to investigate sales performance, customer behaviour, product performance, customer satisfaction and delivery operations.

## 3. Project Objectives

- Analyse overall sales performance.
- Identify high-performing product categories.
- Understand customer purchasing behaviour.
- Evaluate customer satisfaction.
- Investigate delivery delays.
- Identify geographical sales patterns.
- Develop data-driven business recommendations.

## 4. Dataset Information

**Dataset:** Brazilian E-Commerce Public Dataset by Olist

**Source:** Kaggle

**Period:** 2016–2018

The dataset contains approximately 100,000 orders and multiple interconnected datasets.

It includes:
- Customer information
- Order information
- Product information
- Seller information
- Payment details
- Customer reviews
- Delivery information

[Dataset Source](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
